# Chart selection

| Reader's question | Preferred form | Required check |
|---|---|---|
| Change over ordered time | Line | Chronological order, enough points, uncertainty when predictive |
| Compare categories | Sorted horizontal bar or dot | Zero baseline for magnitude, long labels fit |
| Distribution | Histogram/ECDF; boxplot for group comparison | Sample size, bin choice, outliers not hidden |
| Two-variable relationship | Scatter | Common observation grain, sample/volume context, no causal overclaim |
| Matrix/correlation | Heatmap | Scale and clustering/order are explained; redundancy checked |
| Composition | Stacked bar | Denominator explicit; few interpretable parts |
| Ranking | Bar/dot with interval or stability | Rank uncertainty and reversals visible |
| Additive start-to-end change | Waterfall | Components truly add; exact start/end/change labels |
| Exact multi-field lookup | Table | Precision, units, rounding and row ordering are clear |

Avoid pie charts except a rough few-slice composition read. Avoid 3D marks because perspective distorts comparison. If a figure family cannot support the main message honestly, change the form rather than decorate it.
