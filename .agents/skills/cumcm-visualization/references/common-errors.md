# Common visualization errors

| Error | Correction |
|---|---|
| Plot every field | Start from a question and exclude irrelevant fields |
| Decorative dashboard before analysis | Produce only decision-relevant diagnostics/results |
| Axis lacks unit or transformation | Put unit and scale in label/subtitle/caption |
| Legend hides evidence | Direct-label or move the legend outside the data |
| Color is the only distinction | Add marker, line style, fill, order or faceting |
| Bar magnitude uses a truncated baseline | Start at zero unless the chart is explicitly delta-focused |
| Convergence implies optimality | Report it as stopping behavior plus gap/baseline evidence |
| Caption repeats the table | State the message and real-world meaning |
| Figure comes from an old result | Record and verify the current source artifact |
