# 2020 B
## Reality and deliverable

[observed] 在天气影响消耗的地图游戏中，安排行走、停留、补给与挖矿，在截止日前到达终点并尽量保留资金。提交六关策略讨论，第一、二关填写 Result.xlsx。

## Questions and dependencies

[observed] 题面问题及依赖：

1. 单人、全程天气已知：一般最优策略及第一、二关数值方案。
2. 单人、仅当天气已知：在线行动策略，讨论第三、四关。
3. 多人相互影响消耗、收益与价格：分别讨论天气全知且事前固定行动的第五关，以及逐日获取天气和他人行动/资源信息的第六关。

## Inputs, outputs, variables, parameters

[observed] 状态包括日期、地图区域、水箱数、食物箱数和资金；行动是移动至相邻区域、停留、挖矿或在允许位置购买。输入为地图、天气、负重上限、基础消耗、资源价格及收益。各关数值位于附件.docx。

## Objectives, constraints, initial and boundary conditions

[observed] 第 0 天起点购买只能进行一次，起点可停留或返回。沙暴必须停留但可在矿山挖矿；抵达矿山当天不可挖矿。负重不得超限，未到终点时资源耗尽失败。村庄购买价为基准价两倍，终点退回资源价为一半。只共顶点的地区不算相邻。多人情形的具体倍率及部分数学符号无法从正文提取，列为 unverified。

## Data structure and file schema

[observed] 仓库列有题面 DOCX、附件.docx 和 Result.xlsx；只取得题面，附件地图及模板内部结构未读取。题面明确结果中的资源、资金为当天消耗及购买完成后的余额。

## Mathematical structure tags

[inferred] 按题面任务结构归纳，未引用解答：图上路径；离散时间资源状态；动态决策；不完全信息；多人策略相互作用。

## Candidate validation evidence

[expert-rule] 建议逐天核验资源和资金守恒、沙暴规则、邻接合法性及终点期限；信息受限策略只能使用当时可知数据。多人方案需说明同时行动和观察时序。

## Extraction limitations

[unverified] Word 的部分倍率、玩家数与时间下标是嵌入公式对象，正文中缺失，均为 unverified。未读取六关地图及附件数值，因此不能据此卡片直接复现关卡或填入数值策略。
