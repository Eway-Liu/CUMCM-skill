# 2020 C
## Reality and deliverable

[observed] 依据企业交易票据、信誉和外部冲击评估信贷风险，并在银行年度总额约束下设计企业级放贷与利率安排。

## Questions and dependencies

[observed] 题面问题及依赖：

1. 量化 123 家有信贷记录企业风险，在固定年度信贷总额下给出策略。
2. 将风险评价扩展到 302 家无信贷记录企业，总额度 1 亿元。
3. 在第 2 问基础上考虑突发因素对行业/企业的不同影响，调整 1 亿元预算下的信贷策略。

## Inputs, outputs, variables, parameters

[observed] 输入为企业及交易票据信息、已有信用记录、评级、2019 年贷款利率与客户流失率统计。输出为风险量化及是否放贷、额度和年利率。风险分数、违约概率等若采用，均需自行定义并区别于已知评级。

## Objectives, constraints, initial and boundary conditions

[observed] 对获贷企业，额度 10–100 万元、年利率 4%–15%、期限一年；D 级企业原则上不予放贷。第 2/3 问总预算 1 亿元。题面要求权衡风险和信贷策略，没有给出唯一的收益/风险目标函数；模型中采用的权衡需另行声明。

## Data structure and file schema

[observed] 附件 1 是 123 家有信贷记录企业数据，附件 2 是 302 家无信贷记录企业数据，附件 3 是利率—客户流失率统计。题面解释进项、销项、有效、作废和负数发票。三个 XLSX 的名称、字节数及 Git blob 已核实；工作表名、列模式和样本行数未读。

## Mathematical structure tags

[inferred] 按题面任务结构归纳，未引用解答：风险评价；带预算的资源分配；有/无标签迁移；利率与流失关联；情景分析。

## Candidate validation evidence

[expert-rule] 建议按企业分组验证风险模型，单独处理作废及负数发票，复算获贷额度和利率边界；对行业冲击及风险偏好做情景敏感性分析。不能把人工信誉评级等同于违约概率。
