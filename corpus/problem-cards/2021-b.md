# 2021 B
## Reality and deliverable

[observed] 利用催化实验数据研究温度、催化剂组合对乙醇转化和 C4 烯烃选择性的影响，选择高收率条件并提出五次追加实验。

## Questions and dependencies

[observed] 题面问题及依赖：

1. 按催化剂组合分析转化率、选择性与温度的关系，另分析 350°C 下同一实验的时间变化。
2. 比较催化剂组合及温度的影响。
3. 求高收率组合和温度，并另求温度严格低于 350°C 的方案。
4. 设计五次新实验并解释信息价值。

## Inputs, outputs, variables, parameters

[observed] 输入包括 Co 负载量、Co/SiO2 与 HAP 装料比、乙醇供给量、装料方式、反应温度和反应时间；观测为乙醇转化率、各产物选择性。输出为条件—响应关系及优化/实验设置。题面称“乙醇浓度”，示例单位为 ml/min，建模时应保留实际物理含义。

## Objectives, constraints, initial and boundary conditions

[observed] 收率定义为乙醇转化率与 C4 选择性的乘积，百分数须正确换算。A1–A14 使用装料方式 I，B1–B7 使用装料方式 II。限温情形为温度低于 350°C。实验可行域和可选催化剂水平应由附件确定，题面未授权任意外推。

## Data structure and file schema

[observed] 附件 1.xlsx 为性能数据；附件 2.xlsx 为 350°C、给定催化剂条件下不同时间测试。已确认两个文件的仓库元数据，未检查工作表及精确列头。
