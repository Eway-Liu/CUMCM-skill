# 2022 C
## Reality and deliverable

[observed] 依据文物属性和化学成分分析风化规律、玻璃类别与亚类，并识别未知样本。

## Questions and dependencies

[observed] 题面问题及依赖：

1. 分析风化与类型/纹饰/颜色关系，比较各类型有无风化成分规律，并预测风化前成分。
2. 分析高钾、铅钡分类规律，选成分细分亚类，评价合理性和敏感性。
3. 鉴别表单 3 未知样本并分析分类敏感性。
4. 分别分析各类别化学成分关联并比较差异。

## Inputs, outputs, variables, parameters

[observed] 输入为文物编号、类型、纹饰、颜色、表面风化和采样点氧化物比例。输出为关系分析、风化前成分估计、分类/亚类标签及关联差异。文物和采样点是不同粒度。

## Objectives, constraints, initial and boundary conditions

[observed] 成分具有总和约束，但测量总和可偏离 100%；题面将总和 85%–105% 视为有效数据。成分表空白表示未检测到该成分。未风化点可能来自风化文物的局部未风化区域；不同部位可能存在真实成分差异。

## Data structure and file schema

[observed] 附件.xlsx：表单1 为 59×5，文物编号、纹饰、类型、颜色、表面风化；表单2 为 70×15，采样点及 14 种成分；表单3 为 9×16，未知编号、风化和 14 种成分。维度为工作表占用范围，含表头，未代表有效样本数。
