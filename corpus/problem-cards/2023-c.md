# 2023 C
## Reality and deliverable

[observed] 结合蔬菜销售、批发价与损耗数据，设计品类和单品补货/定价，提高生鲜商超收益。

## Questions and dependencies

[observed] 题面问题及依赖：

1. 分析各品类及单品销量分布和相互关系。
2. 分析品类销量与成本加成定价关系，给出 2023-07-01 至 07-07 每日品类补货与定价。
3. 以 06-24 至 06-30 可售品种为基础，制定 07-01 单品组合、补货和价格。
4. 提出进一步需要采集的数据并说明用途。

## Inputs, outputs, variables, parameters

[observed] 输入为六品类商品字典、2020-07-01 至 2023-06-30 销售流水、批发价格和近期损耗。输出为品类/单品销量关系、未来补货量、售价和预期收益。销售流水是交易粒度，补货决策是日粒度。

## Objectives, constraints, initial and boundary conditions

[observed] 蔬菜多数隔日无法再售，凌晨进货时具体单品和进货价格尚不确切。第 3 问可售单品数 27–33，各单品订购至少 2.5 kg，尽量满足各品类需求并最大化收益。打折销售和近期损耗需区分处理；历史销量不自动等于无缺货需求。

## Data structure and file schema

[observed] 附件1 Sheet1 252×4：单品编码/名称、分类编码/名称；附件2 Sheet1 878504×7：日期、扫码时间、单品编码、销量kg、销售单价、销售类型、是否打折；附件3 Sheet1 55983×3：日期、单品编码、批发价。附件4 含品类平均损耗表及 Sheet1 单品损耗表。维度含表头。

## Candidate validation evidence

[expert-rule] 建议按时间留出验证预测和策略，检查退款/销售类型与单位、编码连接、损耗口径；用历史回放比较基准策略，并分析进价、需求弹性及损耗变化。避免未来信息进入训练。
