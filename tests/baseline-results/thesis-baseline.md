# T1：四问数学建模竞赛论文摘要蓝图

## 摘要的整体任务

摘要应在不展示具体数值结果的前提下，交代问题背景、四个子问题的衔接关系、核心模型与求解思路、模型检验及结论性发现。篇幅宜控制在一段或两段内，按“问题—方法—验证—结论”的逻辑组织，避免复述题目和堆砌公式。

## 可直接套用的结构

**背景与目标。** 针对[实际场景]中[核心矛盾或决策需求]，本文以[研究对象及边界]为对象，旨在建立一套兼顾[目标1]、[目标2]与[约束条件]的定量决策方法。

**问题一：数据处理与规律识别。** 首先，针对[原始数据/指标体系]的缺失、量纲差异或异常波动，进行[清洗、标准化、异常值处理]；随后运用[描述统计、相关分析、聚类、回归或降维方法]刻画[关键变量]之间的关系，并得到后续建模所需的[参数、分类结果或特征指标]。

**问题二：基础预测或评价模型。** 在问题一结果的基础上，构建[预测/综合评价/机理]模型，以[误差最小、效益最大或风险最小]为目标，估计[待预测量或评价对象]。通过[交叉验证、残差分析、拟合优度或对比实验]检验模型有效性，并选取表现稳健的方案。

**问题三：优化决策模型。** 考虑[资源、容量、时间、成本、政策等]现实约束，建立以[总成本、总收益、服务水平或公平性]为目标的[线性规划、整数规划、多目标规划、网络优化或动态规划]模型，给出[调度、配置、选址、路径或策略]的优化方案；必要时采用[启发式算法、元启发式算法或分解算法]求解。

**问题四：扩展与稳健性分析。** 针对[不确定性、突发情形、长期变化或新增约束]，在原模型中引入[情景、随机扰动、鲁棒约束、敏感参数或动态机制]，比较不同方案的适应性，提出可执行的分层或阶段性建议。

**综合验证与结论。** 通过[历史样本回代、基准模型比较、敏感性分析、极端情景测试]，说明所建模型在[准确性、稳定性、可解释性或计算效率]方面具有合理性。研究表明，该方法能够为[应用主体]提供[何种决策支持]；同时，模型仍受限于[数据质量、关键假设或外部因素]，后续可从[改进方向]进一步完善。

## 写作要点

1. 四问之间须体现递进：识别或处理数据—建立基础关系—做出优化决策—检验扩展与推广。
2. 每问仅保留“解决对象、方法、产出”三类信息，不展开推导过程。
3. 结论用方向性语言表达，如“提升”“降低”“增强稳健性”，避免未给出的具体数字。
4. 模型名称应服务于问题，不宜罗列与结论无关的算法。

# T2：容量约束、确定性旅行时间运输模型的评价

## 模型概述

该模型通常在给定车辆或线路容量、需求量、节点位置和固定旅行时间的条件下，确定货物或乘客在网络中的分配、发车、路径或配送方案，并以运输成本、总旅行时间、服务水平或资源利用率为目标。

## 优势

1. **结构清晰、易于求解。** 固定旅行时间使时间约束保持确定，容量约束可直接写成线性或整数线性条件，适合采用线性规划、网络流和车辆路径等成熟方法。
2. **决策结果可解释。** 模型能明确呈现每条线路、每个时段或每辆车承担的运输量，便于管理者检查容量是否超限，并据此制定调度方案。
3. **数据要求相对较低。** 相比随机或动态模型，只需使用代表性旅行时间及既定容量，适用于历史数据不足、需要快速形成初步方案的场景。
4. **便于进行方案比较。** 在统一旅行时间条件下，可较直观地比较新增车辆、扩大容量、调整需求或改变网络结构对成本和服务水平的影响。
5. **适合作为基准模型。** 它提供一个可复现的理想化下界或基线，有助于衡量引入拥堵、事故、天气等复杂因素后的额外代价。

## 局限性

1. **忽略旅行时间波动。** 高峰拥堵、天气、事故、装卸延误和道路管制会使实际时间偏离设定值，导致可行路径在实际执行中迟到或错过时间窗。
2. **可能高估资源利用率。** 确定性时间会使车辆衔接和周转安排过于紧凑；一旦出现轻微延误，后续任务可能连锁受影响，预留容量和时间不足。
3. **难以刻画时间依赖性。** 同一路段在不同时段的通行速度不同，固定旅行时间无法反映错峰出行、潮汐交通及路线间的动态替代关系。
4. **容量设定可能过于刚性。** 车辆有效容量还受货物体积、重量、装载顺序、乘客舒适度及临时管制影响，单一固定容量未必反映实际可用能力。
5. **风险与服务可靠性缺失。** 若目标函数只最小化平均成本或平均时间，模型无法直接控制迟到概率、最坏情形损失和关键需求的保障水平。

## 适用范围与改进方向

该模型适合路况稳定、规划周期较短、任务对准点要求不极端的战略或初步调度场景。对于城市配送、应急物流、公共交通高峰调度等时变性强的场景，宜采用分时段旅行时间、情景规划、随机规划或鲁棒优化；同时加入时间窗、服务可靠性约束和容量安全余量。实践中可先以确定性模型生成基础方案，再以历史波动或仿真检验其在扰动下的可执行性。
